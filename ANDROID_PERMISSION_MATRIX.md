## Authorization Mechanism Summary

1. **System Special Access (Settings Toggles)**:
   - `PACKAGE_USAGE_STATS` (Usage Access)
   - `SYSTEM_ALERT_WINDOW` (Display over other apps)
   - `SCHEDULE_EXACT_ALARM` (Alarms & Reminders)
   *Rule: Cannot be requested via standard runtime dialog (`requestPermissions`). The app must launch targeted settings intents and monitor return via `onResume()` / `AppState`.*

2. **Service Binding Permissions**:
   - `android.permission.BIND_ACCESSIBILITY_SERVICE`
   - `android.permission.BIND_VPN_SERVICE`
   *Rule: Declared as an attribute on `<service android:permission="...">` to ensure only the Android OS can bind to the service. Must NEVER be placed inside `<uses-permission>`.*

3. **Runtime Permissions**:
   - `POST_NOTIFICATIONS` (Android 13+)
   *Rule: Requested using standard runtime permission dialog.*

4. **Service Declaration Permissions**:
   - `FOREGROUND_SERVICE`
   - `FOREGROUND_SERVICE_SPECIAL_USE`
   *Rule: Declared in `<uses-permission>` and matched to `<service android:foregroundServiceType="...">`.*
